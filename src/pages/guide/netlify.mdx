# Netlify

## 1. Get your site online

1. Create a free Netlify account.
2. Drag your site folder onto the Netlify dashboard, or connect a Git repo.
3. Rename the site so it has a clean address: **Site configuration → Change
   site name** → `your-site`. Your URL becomes `https://your-site.netlify.app`.

## 2. Submit your request

On the [submit form](/submit):

- **Record type:** `CNAME`
- **Target:** `your-site.netlify.app`

## 3. After it is live

1. Go to **Domain management → Add a domain**.
2. Enter `yourname.filipino-talent.com` and add it.
3. Netlify checks the DNS record we published and enables HTTPS.

## Notes

- Use the `netlify.app` address, not a deploy-preview URL.
